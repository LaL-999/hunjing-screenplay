# 剧本术语速查 — 给非专业用户的录视频口播稿

> 这份文档列了「剧创态」平台界面上会出现的所有剧本行业术语。录视频时如果讲到某个术语,看这里照着说就行。
> 来源:好莱坞剧本格式标准 (Hollywood Spec Script Format) + 中国影视行业惯例。

---

## 一、场景头(SCENE HEADING)

每个 SCENE 卡顶部那一行,比如:

> `SCENE 003   INT. 斯宾塞教授办公室 — 日`

由 3 个部分组成,**每个剧本都必须有**:

### `INT.` / `EXT.` / `INT/EXT.`(场景类型)

| 缩写 | 全称 | 含义 |
|---|---|---|
| **INT.** | INTERIOR(室内) | 在房间内、车内、室内场景 |
| **EXT.** | EXTERIOR(室外) | 在户外、街道、山野等 |
| **INT/EXT.** | 内外混合 | 比如:车内拍摄,但能看到车外街景 |

**为什么重要**:导演看到 INT./EXT. 立刻知道**要不要搭室外景或租场地**,直接影响拍摄预算和日程安排。

口播参考:
> "每场戏开头都标了 INT. 或 EXT. —— INT. 就是室内,EXT. 就是室外,这是导演看一眼就能判断要怎么拍的关键信息。"

### `地点名`

比如 `斯宾塞教授办公室`、`潘西中学`、`汤姆孙山`。

**写法规范**:一句话能定位的具体地点,不要写成"某教室"或"某街道"。

### `时间`

| 中文 | 英文等价 | 含义 |
|---|---|---|
| **日** | DAY | 白天,自然光为主 |
| **夜** | NIGHT | 夜晚,人工光 |
| **黄昏** | DUSK | 太阳即将落山 |
| **黎明** | DAWN | 太阳即将升起 |
| **深夜** | NIGHT(LATE)| 凌晨前 |
| **凌晨** | DAWN(EARLY)| 天还黑 |
| **连续** | CONTINUOUS | 紧接上一场,时间无间隔 |
| **稍后** | LATER | 过了一段时间 |

**为什么重要**:摄影组按时间安排灯光方案,服化道按时间安排场景细节(夕阳的暖光 / 早晨的露水)。

## 二、剧本元素(每个 SCENE 内的 5 种构件)

### 1. 动作 (ACTION)

衬线字体的段落,描写**可见、可听**的实物动作。

> "霍尔顿盯着墙上泛黄的毕业照,沉默良久。"
> "门吱呀一声打开。"

口播参考:
> "ACTION 是导演和演员能看的'画面描写'—— 不能写心理活动,只能写镜头能拍到的东西。"

### 2. 对白 (DIALOGUE)

角色名居中大写 + 居中对白:

```
        霍尔顿
       (低声)
   我知道您要说什么。我搞砸了。
```

- **角色名居中大写**:这是行业铁律(Hollywood Spec Script Format)
- **括号里的小字** (低声 / 不耐烦地 / 突然激动) = **括号提示语 (Parenthetical)**,演员的微表情指引

口播参考:
> "对白严格按好莱坞标准排版 —— 角色名居中大写,表演提示括号小字,这是导演拿来直接拍的格式。"

### 3. 画外声(VOICEOVER)— **V.O. 和 O.S. 必须区分**

V.O. 紫色 / O.S. 蓝色,**这是剧本界一定要区分的细节**:

| 标识 | 全称 | 用法 | 制片影响 |
|---|---|---|---|
| **(V.O.)** | Voice-Over | 角色**不在场景里**的画外音 — 内心独白、旁白、回忆 | **后期录音棚配音** |
| **(O.S.)** | Off-Screen | 角色**在场景里**,但镜头没拍到 — 门外说话、隔壁喊叫 | **现场同期录音** |

举例:
- "霍尔顿 **(V.O.)**:如果你真的想听..." → 这是霍尔顿的内心独白,后期配
- "斯宾塞 **(O.S.)**:进来吧,孩子。" → 斯宾塞就在门内,只是镜头还在霍尔顿身上,现场录

口播参考:
> "我们的剧本明确区分 V.O. 和 O.S. —— V.O. 是后期配音的画外音,O.S. 是现场录的镜头外声音。这是其他 AI 工具不区分的,导演看到立刻知道要不要现场录音。"

### 4. 场景过渡 (TRANSITION)

每个 SCENE 卡底部的等宽大写英文:`CUT_TO` / `FADE_OUT` / `DISSOLVE_TO` 等。

| 标识 | 中文 | 视觉效果 |
|---|---|---|
| **CUT_TO** | 切换 | 硬切到下一场,最常见 |
| **FADE_OUT** | 淡出 | 画面渐黑,通常用在 act 结尾 |
| **FADE_IN** | 淡入 | 画面从黑渐显,act 开头 |
| **DISSOLVE_TO** | 溶解到 | 当前画面渐渐变为下一场,通常表示时间流逝 |
| **MATCH_CUT** | 匹配剪 | 两场画面构图相似的转换(创意感强)|
| **SMASH_CUT** | 猛切 | 剧烈对比的切换,常用于震撼时刻 |
| **CONTINUOUS** | 连续 | 时间无间断地切到下一场 |

口播参考:
> "每场结尾的 CUT_TO / DISSOLVE_TO 等是给剪辑师的指令 —— 告诉他这两场之间用什么转场方式。"

## 三、改编决策(差异化核心 — 5 种专业改编手法)

把小说的内心独白改成剧本,有 5 种行业级手法。我们的 AI 不替作者选,而是**全给出来让作者拍板**:

| 颜色 | 标识 | 中文 | 何时用 |
|---|---|---|---|
| 🟣 紫色 | voiceover | **V.O. 画外音** | 保留主角独特叙述声音(《麦田守望者》《教父》)|
| 🔵 蓝色 | action_externalize | **动作外化** | 心理可以被身体表达(攥紧拳头/砸碎杯子) |
| 🟤 棕色 | subtext | **潜台词** | 复杂情绪、不愿直说 — 用看似无关的对话暗示真情绪 |
| 🟢 绿色 | symbolism | **意象化** | 用具体道具或空镜替代抽象情绪(滴水的龙头/枯萎的盆栽) |
| ⚫ 灰色 | delete | **删除** | 后续场景或对白能替代,删了反而节奏更紧 |

口播参考:
> "我们的核心创新是'改编决策'—— 别的 AI 工具会偷偷帮你选一种,我们把 5 种专业改编手法全列给作者,每种带利弊和 AI 推荐,作者自己拍板。这才是真正尊重创作者主权的工具。"

## 四、保真度评分(质量诊断)

每个 SCENE 卡右上角的徽章 `中 65` / `高 87`,**4 个维度加权出综合分**:

| 维度 | 含义 | 高分意味着 |
|---|---|---|
| **对白覆盖度** | dialogue + V.O. 字数 / 原文字数 | 不能太低(没改编)也不能太高(灌水) |
| **角色一致性** | 在场角色名是否在原小说出现 | 100 = LLM 没编新角色 |
| **元素密度** | element 数 / 段落数 | 越高说明改编越细致(2-7 个最优) |
| **决策完整度** | 内心独白有没有改编决策方案 | 100 = 全部内心独白都有备选 |

**等级映射**:
- **高保真** (≥80):AI 还原度高,可放心使用
- **中保真** (55-80):大部分OK,看 issues 复核
- **低保真** (<55):建议人工大改

口播参考:
> "我们对每场戏都打了保真度分 — 不是吹自己 AI 做得好,而是诚实告诉作者:这场我们改得怎么样,哪些维度可能有问题。AI 自己当裁判,这是创作工具的良心。"

## 五、剧本结构(三幕 + 张力曲线)

右上栏「结构报告」展示:

### 三幕结构

经典编剧理论(亚里士多德 → 麦基),一个故事的标准比例:

| 幕 | 中文别名 | 比例 | 内容 |
|---|---|---|---|
| **第一幕** | 立 / Setup | ~25% | 介绍世界、人物、激励事件 |
| **第二幕** | 冲 / Confrontation | ~50% | 主角追求目标遇到阻碍,情节最厚 |
| **第三幕** | 收 / Resolution | ~25% | 高潮 + 收束 |

### 关键节点 (Story Beats)

- **触发事件** (Inciting Incident) — 第一幕末尾,把主角推上故事的"不归路"
- **中点反转** (Midpoint) — 第二幕中段的重大转折
- **高潮** (Climax) — 第三幕,矛盾的最终爆发

### 张力曲线 (Tension Curve)

每场打 0-100 张力分,综合 5 个信号:
- 元素密度
- 冲突词频(怒/喊/质问 等)
- 内心独白数(转折信号)
- 角色对峙数(>=3 = 多方对峙)
- 保真度

**好剧本节奏**:像呼吸 — 长场 30% / 中场 50% / 短场 20%。**严禁全是 15 秒短切片**。

口播参考:
> "右上是结构报告 —— 张力曲线 + 三幕分区 + 关键节点全自动检测,标记哪一场是'触发事件'、哪一场是'高潮'。这是编剧理论里的核心节拍,我们用程序级算法自动找出来,作者不需要懂编剧理论也能看懂自己作品的结构问题。"

## 六、AI 优化的两种模式

| 模式 | 入口 | 干啥 |
|---|---|---|
| **单场精修** | 鼠标 hover SCENE 卡 → 右上 "AI 优化" 按钮 | 委托 AI 重写这一场 — 按 fidelity 诊断改 |
| **整本重排** | 结构报告底部 "整本重排" 按钮 | 委托 AI 通读全本 — 加冲突场 / 拆合并 / 调三幕节奏 |

**两个模式共用一个 LLM 引擎,只是范围不同**。优化结果会:
1. 保存为新版本(不覆盖原稿)
2. 顶栏 dropdown 显示版本树:稿 1 → 稿 2 → 稿 3...
3. 可以随时切回任意历史版本

口播参考:
> "AI 优化分两种 — 想精修一场,鼠标移到那场上方有'AI 优化'按钮;想让 AI 整体重排,结构报告底部有'整本重排'。每次优化都新存一个版本,作者可以反悔回去,版本树永远在。"

## 录视频结构推荐(3-5 分钟)

1. **0:00-0:30 — 痛点引入**
   "传统 AI 工具把小说转剧本,要么平铺直叙,要么偷偷替作者做决定。我们想让 AI 真正成为编剧的助手,而不是替代者。"

2. **0:30-1:30 — 上传 + 生成基线**
   拖文件 → 显示后端跑 pipeline → 出第一版剧本

3. **1:30-2:30 — 行业级排版展示**
   滚动剧本 → 指 INT./EXT. + 角色名居中 + 括号提示 + V.O./O.S.
   "这不是 demo,是真正能给导演用的工业标准格式。"

4. **2:30-3:30 — 改编决策 + 5 备选**
   点开任意 V.O. 元素 → 展开改编决策面板 → 展示 5 选项 + 利弊
   "这是别的 AI 工具不会给你的 — 作者主权,5 种专业手法,你来拍板。"

5. **3:30-4:30 — AI 优化 + 版本树**
   点"AI 优化"按钮 → 显示前置质量预检 → modal 跑完后 diff 对比
   切版本演示版本树

6. **4:30-5:00 — 结构报告**
   滚到顶 → 指张力曲线 + 三幕 + 触发事件标记
   "我们用程序级算法自动找剧本的'关键节拍',作者不懂编剧理论也能看懂结构问题。"

## 录视频时不要说的"AI 工程师味"词

| 避免说 | 改说 |
|---|---|
| LLM | AI / 语言模型 |
| Token | 字数 / 调用次数 |
| Pipeline | 流水线 / 工作流 |
| API | 后端接口 |
| Schema | 数据结构 / 格式规范 |
| Endpoint | 接口 |
| Fidelity | 保真度 / 还原度 |
| Embeddings | (不用提)|

**用人话讲产品,讲剧本工艺,不讲实现细节**。
